# 风险复核资源配置与影响面覆盖

本地资料用于理解复核资源配置与影响面覆盖所涉及的记录关系。文件均为合成数据，标识符不对应真实个人、机构或账号。

## 目录

- `data/`：UTF-8 编码、首行为字段名的逗号分隔资料。空字段表示资料未提供，不代表数值为零或业务状态已否定。
- `tests/`：只检查资料文件可读取和格式结构，不预设分析结果。

日期使用 ISO 8601 写法；时间字段为空时表示该记录没有提供时间。金额和计数字段以文本保存，具体解释须结合字段名及记录上下文。

## 运行与检查

需要 Python 3.11 或更高版本，无第三方运行依赖。运行 `python3 -m unittest discover -s tests` 检查合成资料是否可读；项目分析能力由后续开发提供。
